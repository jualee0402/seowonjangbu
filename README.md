# 서원동 초과근무·급량비 계산기

서원동 주민센터 공무원을 위한 초과근무 시간 및 급량비 자동 계산 모바일 웹 앱

**개발자:** 이주아 (jualee0402)  
**배포일:** 2026.04.28
**서비스 주소:** https://seowonjangbu.vercel.app


## 주요 기능

- 출퇴근 버튼으로 즉시 기록
- 과거 날짜 수동 소급 입력
- 평일/휴일 구분 초과근무 자동 계산
- 공무원 복무 규정 기준 급량비 자동 계산
- 장부식당 / 내돈내산 식사 기록 분리 관리
- 이번 달 누적 현황 대시보드


## 계산 기준

**평일 초과근무**
- 오전(9시 이전) + 오후(18시 이후) 합산 후 1시간 차감
- 하루 최대 4시간 인정

**휴일 초과근무**
- 전체 근무시간 인정
- 하루 최대 4시간

**급량비**
- 오전 1시간 이상 → 1개
- 오후 1시간 이상 → 1개
- 각각 미만이어도 합산 60분 이상 → 1개
- 하루 최대 2개 / 월 최대 20개


## 기술 스택

프론트엔드: React 18 + TypeScript 
빌드 도구: Vite 5 
스타일: Tailwind CSS v4 
배포: Vercel 
데이터 저장: localStorage
앱화: PWA 


## 사용 방법

1. 스마트폰으로 https://seowonjangbu.vercel.app 접속
2. 크롬 브라우저 메뉴 → **홈 화면에 추가** (앱처럼 설치)
3. 매일 출근 시 **출근 기록** 버튼 탭
4. 퇴근 시 **퇴근 기록** 버튼 탭
5. 놓친 날은 **지난 날짜 수동 추가** 버튼으로 소급 입력


## 특징

- **개인정보 보호:** 모든 데이터는 본인 기기에만 저장, 서버 전송 없음
- **무료 운영:** 서버 없는 구조로 유지비용 0원
- **다중 사용자:** 링크 공유 시 각자 기기에 독립적으로 저장
- **오프라인 작동:** 인터넷 없이도 기록 및 조회 가능
- **PWA 지원:** 홈화면 설치 후 네이티브 앱처럼 실행


## 유의사항

- 본 앱은 **참고용**이며 공식 급여 시스템과 연동되지 않습니다
- 데이터는 브라우저별로 독립 저장됩니다 (크롬 ≠ 삼성브라우저)
- 앱을 삭제하거나 브라우저 데이터를 초기화하면 기록이 사라집니다
- 복무 규정 변경 시 계산 로직 업데이트가 필요할 수 있습니다
