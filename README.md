# 서원동 초과근무·급량비 계산기

서원동 주민센터 공무원을 위한 초과근무 시간 및 급량비 자동 계산 모바일 웹 앱

**개발자:** 이주아 (jualee0402)  
**배포일:** 2026.04.28

**서비스 주소:** https://seowonjangbu.vercel.app


## 주요 기능

- 출퇴근 버튼으로 즉시 기록
- 지난 날짜 근무 직접 입력 (저장 전 초과근무·급량비 미리보기)
- 평일/휴일 구분 초과근무 자동 계산
- 공휴일·대체공휴일 자동 반영, 임시공휴일 등 평일 휴일 직접 지정
- 공무원 복무 규정 기준 급량비 자동 계산
- 장부식당 / 내돈내산 식사 기록 분리 관리
- 월별 내역(근무·식사)과 장부 잔액 요약


## 화면 구성

- **위 (입력):** 오늘 날짜·시각, 출근/퇴근 기록, `근무 직접 입력`, `식사 기록`
- **아래 (월별 내역):** 월 이동, 장부 잔액(급량비 − 장부 사용), 초과근무·급량비 현황, `근무 내역` / `식사 내역` 표
- 내역의 줄을 누르면 계산 내역과 삭제 버튼이 나옴
- `휴일 설정`: 달력에서 평일을 눌러 임시공휴일 등으로 지정하거나, 공휴일을 평일로 계산하도록 변경


## 계산 기준

**휴일 판정**
- 토·일, 관공서 공휴일(대체공휴일·선거일 포함)은 자동으로 휴일
- 2026년부터 노동절(5/1)·제헌절(7/17) 공휴일 포함
- 임시공휴일 등은 `휴일 설정`에서 직접 지정 (기기에 저장)
- 공휴일 목록: `src/lib/holidays.ts` (2026~2027년 월력요항 기준, 2028년 잠정)

**평일 초과근무**
- 오전(9시 이전) + 오후(18시 이후) 합산 후 1시간 차감
- 1일 상한 없음 (2026.10.1.부터)

**휴일 초과근무**
- 전체 근무시간 인정
- 1일 상한 없음 (2026.10.1.부터)

**1일 4시간 상한 폐지**
- 「공무원수당 등에 관한 규정」 개정으로 2026년 10월 1일부터 1일 4시간 상한 폐지
- 2026년 9월 30일 이전 기록은 당시 기준(1일 4시간)으로 계산
- 월 57시간 한도는 화면에 참고로만 표시 (계산에는 적용하지 않음)

**급량비**
- 평일: 오전 1시간 이상 → 1개, 오후 1시간 이상 → 1개
- 평일: 각각 미만이어도 합산 60분 이상 → 1개
- 휴일: 1시간 초과 근무 → 1개
- 하루 최대 2개 / 월 최대 20개 / 1개 9,000원


## 기술 스택

1. 프론트엔드: React 18 + TypeScript 
2. 빌드 도구: Vite 5 
3. 스타일: Tailwind CSS v4 
4. 배포: Vercel 
5. 데이터 저장: localStorage
6. 앱화: PWA 

**소스 구성**
- `src/App.tsx`: 화면
- `src/lib/worktime.ts`: 초과근무·급량비 계산
- `src/lib/holidays.ts`: 공휴일 목록과 휴일 판정

**저장 키 (localStorage)**
- `seowon_work_records_v1`: 근무 기록
- `seowon_ledger_entries_v1`: 식사 기록
- `seowon_holidays_v1`: 직접 바꾼 휴일 설정


## 사용 방법

1. 스마트폰으로 https://seowonjangbu.vercel.app 접속
2. 크롬 브라우저 메뉴 → **홈 화면에 추가** (앱처럼 설치)
3. 매일 출근 시 **출근 기록** 버튼 탭
4. 퇴근 시 **퇴근 기록** 버튼 탭
5. 놓친 날은 **근무 직접 입력** 버튼으로 소급 입력
6. 장부 식당에서 먹은 날은 **식사 기록** 버튼으로 금액 입력
7. 임시공휴일이 생기면 **휴일 설정**에서 그 날짜를 휴일로 지정


## 특징

- **개인정보 보호:** 모든 데이터는 본인 기기에만 저장, 서버 전송 없음
- **무료 운영:** 서버 없는 구조로 유지비용 0원
- **다중 사용자:** 링크 공유 시 각자 기기에 독립적으로 저장
- **오프라인 작동:** 인터넷 없이도 기록 및 조회 가능
- **PWA 지원:** 홈화면 설치 후 네이티브 앱처럼 실행


## 유의사항

- 본 앱은 **참고용**이며 공식 급여 시스템과 연동되지 않습니다
- 데이터는 브라우저별로 독립 저장됩니다 (크롬 ≠ 삼성브라우저)
- 앱을 삭제하거나 브라우저 데이터를 초기화하면 기록이 사라집니다
- 복무 규정 변경 시 계산 로직 업데이트가 필요할 수 있습니다
- 매년 다음 해 공휴일(월력요항)이 발표되면 `src/lib/holidays.ts` 갱신이 필요합니다
