# 초근밥

서원동 주민센터 공무원을 위한 **초과근무·급량비 계산 앱**이에요.
출퇴근을 찍으면 초과근무 시간과 급량비를 규정대로 계산하고, 장부 식당 잔액까지 한눈에 보여 줘요.

> 초근(초과근무)하면 밥이 나온다. 아이콘은 밤하늘 달 아래 웃는 밥 한 공기예요.
> 처음 이름은 **서원장부**였고, **야근밥**을 거쳐 지금의 **초근밥**이 됐어요.

**서비스 주소:** https://seowonjangbu.vercel.app  
**버전:** 1.8.0 (2026.10.29)  
**처음 배포:** 2026.04.28 (서원장부)  
**개발:** 이주아 · 서울특별시 관악구 서원동  
**문의:** jualee0402@ga.go.kr · GitHub [jualee0402](https://github.com/jualee0402)


## 주요 기능

- **출퇴근 버튼 하나:** 출근하면 `출근`, 퇴근하면 같은 자리의 `퇴근`. 근무 기록은 하루에 1개만 남아요
- **초과근무 자동 계산:** 평일(09시 전 + 18시 후 − 1시간)과 휴일(근무 전체)을 나눠서 계산
- **운영시간 반영:** 평일 06~23시, 휴일 07~22시 밖 근무는 빼고 계산 (그 날 8시간 이상이면 예외)
- **휴일 자동 반영:** 토·일, 공휴일·대체공휴일은 자동으로 휴일. 임시공휴일 같은 날은 직접 지정
- **수당 시간:** 기본 10시간 + 실적(월 최대 47시간, 분 단위 버림)
- **급량비와 장부 잔액:** 급량비 개수(월 최대 20개), 장부 식당 사용액과 잔액. 내돈내산 식사는 따로 기록
- **기록 수정:** 퇴근을 깜빡한 날, 자정을 넘긴 근무도 고칠 수 있어요
- **계산 규칙 바꾸기:** 규정이 바뀌면 시행 월부터 새 규칙을 추가. 지난 기록은 그때 규칙 그대로 계산
- **내 기기에만 저장:** 서버로 보내는 정보가 없어요


## 설치와 사용

**설치 (홈 화면에 앱처럼)**
- 안드로이드: 크롬으로 접속 → 메뉴(⋮) → `홈 화면에 추가` 또는 `앱 설치`
- 아이폰: 사파리로 접속 → 공유 버튼 → `홈 화면에 추가`

**매일 쓰기**
1. 출근하면 **출근**, 퇴근하면 같은 자리의 **퇴근** (퇴근하면 `퇴근 완료`로 바뀌어요)
2. 장부 식당에서 먹으면 **식사 입력** → `장부 식당`, 내 돈으로 먹었으면 `내돈내산`
3. 깜빡한 날은 **근무 입력**으로 소급 입력 (이미 기록이 있는 날이면 `그 기록 수정`으로 안내)
4. 잘못 찍었으면 목록에서 그 줄을 눌러 **수정** 또는 **삭제**
5. 임시공휴일이 생기면 달력 아이콘(**휴일 설정**)에서 그 날짜를 휴일로 지정
6. 규정이 바뀌면 톱니바퀴(**설정**) → **계산 규칙**에서 시행 월부터 새 규칙 추가
7. 동료에게 알려 주려면 설정 맨 아래 **주소**를 눌러 공유 (공유가 안 되는 기기에서는 주소 복사)


## 화면 구성

- **오늘 (맨 위 남색 영역):** 날짜·시각, 출근/퇴근 버튼, `근무 입력`, `식사 입력`
- **월 요약:** 초과근무 실적과 급량비 개수를 한도 막대로 보여 줘요 (최대 47시간·20개, 넘으면 주황). 그 아래 수당 시간·장부 사용·잔액. 요약을 누르면 계산 내역(기본+실적, 급량비 금액, 내돈내산)
- **근무 목록:** 날짜, 출퇴근 시각, 급량비(밥그릇 아이콘), 초과근무(파란 숫자). 줄을 누르면 계산 내역과 수정·삭제 버튼. 운영시간 밖이라 뺀 시간도 여기에 표시돼요. 예전에 같은 날 여러 번 찍힌 기록에는 `중복` 표시
- **식사 목록:** `장부 사용`(남색)·`내돈내산`(회색) 꼬리표, 메모, 금액
- **휴일 설정 (달력 아이콘):** 평일을 임시공휴일·대체공휴일·기타 휴일로 지정하거나, 공휴일을 평일로 계산하도록 변경
- **설정 (톱니바퀴):** 휴일 설정, 계산 규칙, 데이터 초기화, 앱 정보(버전·개발·문의·주소)
- **계산 규칙:** 정규 근무 시간, 운영시간, 공제, 하루 최소·상한, 월 상한, 기본 초과근무, 급량비 금액·기준을 시행 월별로 설정. 항목 설명은 `?` 버튼을 누르면 보여요
- PC처럼 넓은 화면에서는 휴대폰 화면처럼 가운데 한 줄로 보여요


## 계산 기준

아래 숫자는 기본값이에요. 규정이 바뀌면 앱의 `설정 → 계산 규칙`에서 시행 월부터 새 규칙을 추가하면 돼요. 직접 바꾼 규칙은 그 기기에만 저장돼요.

### 초과근무

| | 평일 | 휴일 (토·일·공휴일·지정한 휴일) |
|---|---|---|
| 인정 시간 | 09시 전 + 18시 후 | 근무한 전체 시간 |
| 운영시간 | 06:00 ~ 23:00 | 07:00 ~ 22:00 |
| 공제 | 1시간 | 없음 |
| 인정 조건 | 하루 1시간 이상 (공제 전 기준) | 하루 1시간 이상 |
| 하루 상한 | 없음 (2026.10.1.부터, 그 전 기록은 4시간) | 없음 (2026.10.1.부터, 그 전 기록은 4시간) |

- 운영시간 밖 근무는 초과근무로 치지 않아요. 다만 그 날 초과근무(평일은 공제 전)가 **8시간 이상**이면 소관 국·소장 결재 대상이라 운영시간 밖 근무도 인정해요. 2026년 10월 기록부터 적용하고, 그 전 기록은 예전 방식 그대로 계산해요
- 근무 기록은 출근한 날 기준으로 하루 1개예요. 자정을 넘긴 근무도 출근한 날의 기록이라 공제는 1번만 해요
- 월 상한은 57시간이고, 기본 초과근무(정액분) 10시간이 여기에 포함돼요. 그래서 기록으로 인정되는 **실적은 월 최대 47시간**이에요
- 월 실적 합계에서 1시간 미만(분 단위)은 버려요
- **수당 시간 = 기본 10시간 + 실적**

### 급량비

| | 기준 |
|---|---|
| 평일 | 09시 전 1시간 이상 → 1개, 18시 후 1시간 이상 → 1개. 둘 다 모자라도 합쳐서 1시간 이상이면 1개 (하루 최대 2개) |
| 휴일 | 1시간 넘게 근무 → 1개 |

- 월 최대 20개, 1개 9,000원
- 잔액 = 급량비 금액 − 장부 사용액 (내돈내산은 잔액에 넣지 않아요)

### 휴일 판정

- 토·일, 관공서 공휴일(대체공휴일·선거일 포함)은 자동으로 휴일
- 2026년부터 노동절(5/1)·제헌절(7/17)도 공휴일
- 공휴일 목록: `src/lib/holidays.ts` (2026~2027년 월력요항 기준, 2028년은 잠정)
- 임시공휴일 등은 `휴일 설정`에서 직접 지정 (그 기기에 저장)

### 근거

- 「지방공무원 수당 등에 관한 규정」 제15조제4항: 2026.10.1. 개정 시행으로 1일 4시간 상한 삭제, 월 57시간 상한 유지
- 「지방공무원 보수업무 등 처리지침」: 하루 1시간 이상 근무해야 인정, 평일 1시간 공제, 월간 합산 시 분 단위 버림, 이틀에 걸친 근무는 시작한 날 기준 1번만 공제
- 초과근무 운영시간 안내 (2026.10.2. 기준): 평일 06:00~23:00, 휴일 07:00~22:00. 소관 국·소장 결재로 하루 8시간 이상 초과근무하면 적용하지 않음


## 유의사항

- **참고용**이에요. 공식 급여·인사 시스템(인사랑 등)과 연동되지 않고, 실제 인정 시간은 기관 기준을 따라요
- 개인용무시간 제외, 월 상한 예외 승인(현안·재난 업무 등)은 반영하지 않아요
- 8시간 이상 근무한 날은 국·소장 결재를 받았다고 보고 운영시간 밖 근무까지 계산해요
- 지문 확인 등 기관의 근무 확인에서 인정되지 않은 날은 앱에서 그 날 기록을 지우거나 고쳐서 맞춰 주세요
- 기록은 그 기기, 그 브라우저에만 저장돼요 (크롬 ≠ 삼성 인터넷, 아이폰은 사파리 ≠ 홈 화면 앱)
- 브라우저 데이터를 지우면 기록도 사라져요. 아이폰은 홈 화면에 추가한 앱을 지우면 그 안의 기록도 함께 지워질 수 있어요
- 앱을 처음 열 때는 인터넷이 필요해요. 연 뒤의 기록과 계산은 모두 기기 안에서 해요


## 개발

**기술 스택**
- React 18 + TypeScript, Vite 5, Tailwind CSS v4
- 글꼴: Pretendard (jsDelivr에서 불러옴, 안 되면 기기 기본 글꼴)
- 저장: 브라우저 localStorage (서버 없음)
- PWA: `public/manifest.json`, `public/sw.js`
- 배포: Vercel. `main`에 합치면 자동으로 배포되고, PR마다 미리보기 주소가 생겨요

**명령어**

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 배포용 빌드
npm run typecheck  # 타입 검사
```

**소스 구성**

| 파일 | 내용 |
|---|---|
| `src/App.tsx` | 화면 전체 |
| `src/lib/worktime.ts` | 초과근무·급량비 계산, 월 합계 |
| `src/lib/rules.ts` | 계산 규칙(시행 월별)과 기본값 `DEFAULT_RULES` |
| `src/lib/holidays.ts` | 공휴일 목록과 휴일 판정 |
| `src/lib/appInfo.ts` | 설정 화면 앱 정보 (버전·문의·주소) |
| `src/assets/chogeunbap.svg` | 아이콘 원본 (앱 맨 위 로고) |
| `public/` | 아이콘 PNG(192·512·안드로이드 마스크용·아이폰 180), 파비콘, manifest, 서비스 워커 |

**저장 키 (localStorage)**

앱 이름이 바뀌어도 키는 처음(서원장부) 그대로라 기록이 이어져요.

| 키 | 내용 |
|---|---|
| `seowon_work_records_v1` | 근무 기록 |
| `seowon_ledger_entries_v1` | 식사 기록 |
| `seowon_holidays_v1` | 직접 바꾼 휴일 |
| `seowon_rules_v1` | 직접 바꾼 계산 규칙 (기본값 그대로면 저장하지 않음) |

**업데이트할 때**
- 버전: `src/lib/appInfo.ts`의 `version`을 올리고 아래 업데이트 내역에 추가
- 규정이 바뀌어 모두의 기본값을 바꿀 때: `src/lib/rules.ts`의 `DEFAULT_RULES`에 시행 월부터 새 규칙 추가
- 매년 다음 해 월력요항이 나오면 `src/lib/holidays.ts`에 공휴일 추가
