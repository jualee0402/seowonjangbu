# 야근밥

서원동 주민센터 공무원을 위한 초과근무 시간 및 급량비 자동 계산 모바일 웹 앱 (서원동 초과근무·급량비 계산기)

야근하면 밥이 나온다: 밤하늘 달 아래 웃는 밥 한 공기가 아이콘이에요.

**개발자:** 이주아 (jualee0402)  
**배포일:** 2026.04.28

**서비스 주소:** https://seowonjangbu.vercel.app


## 주요 기능

- 출퇴근 버튼 하나로 즉시 기록 (출근 중이면 퇴근 버튼으로 바뀜)
- 근무 기록은 하루에 1개만 (퇴근 뒤에는 `퇴근 완료`, 같은 날 직접 입력도 막고 그 기록 수정으로 안내)
- 지난 날짜 근무 직접 입력 (저장 전 초과근무·급량비 미리보기)
- 평일/휴일 구분 초과근무 자동 계산
- 공휴일·대체공휴일 자동 반영, 임시공휴일 등 평일 휴일 직접 지정
- 공무원 복무 규정 기준 급량비 자동 계산
- 장부식당 / 내돈내산 식사 기록 분리 관리
- 근무·식사 기록 수정·삭제 (퇴근 누락, 자정 넘긴 근무도 수정 가능)
- 계산 규칙 직접 설정: 규정이 바뀌면 시행 월부터 새 규칙 적용
- 월별 내역(근무·식사)과 장부 잔액 요약


## 화면 구성

- **위 (오늘):** 날짜·시각, `출근`/`퇴근` 버튼 하나, `근무 입력`, `식사 입력`
- **아래 (월별 내역):** 월 이동, 요약, `근무` / `식사` 목록
- 요약: 초과근무 실적·급량비 개수와 한도 막대(최대 47시간·20개, 넘으면 주황), 그 아래 수당 시간·장부 사용·잔액
- 요약을 누르면 계산 내역(기본+실적, 급량비 금액, 내돈내산)이 펼쳐짐
- 목록의 밥그릇 아이콘 = 급량비 개수, 파란 숫자 = 초과근무. 줄을 누르면 계산 내역과 수정·삭제 버튼
- 달력 아이콘(`휴일 설정`): 평일을 눌러 임시공휴일 등으로 지정하거나, 공휴일을 평일로 계산하도록 변경
- 톱니바퀴(`설정`) → `계산 규칙`: 정규 근무 시간, 공제, 하루 상한, 월 한도, 급량비 금액·개수 기준을 시행 월별로 설정. 항목 설명은 `?` 버튼을 누르면 보임
- PC처럼 넓은 화면에서는 앱이 가운데 한 줄로 보임
- 글꼴: Pretendard (인터넷이 안 되면 기기 기본 글꼴)


## 계산 기준

아래 숫자는 기본값이에요. 규정이 바뀌면 앱의 `설정 → 계산 규칙`에서 시행 월부터 새 규칙을 추가하면 되고, 지난 기록은 그때 규칙으로 계산돼요. 모두에게 기본값을 바꾸려면 `src/lib/rules.ts`의 `DEFAULT_RULES`를 고치세요. 직접 설정한 규칙은 그 기기에만 저장돼요.

**휴일 판정**
- 토·일, 관공서 공휴일(대체공휴일·선거일 포함)은 자동으로 휴일
- 2026년부터 노동절(5/1)·제헌절(7/17) 공휴일 포함
- 임시공휴일 등은 `휴일 설정`에서 직접 지정 (기기에 저장)
- 공휴일 목록: `src/lib/holidays.ts` (2026~2027년 월력요항 기준, 2028년 잠정)

**평일 초과근무**
- 오전(9시 이전) + 오후(18시 이후) 합산 후 1시간 차감
- 1일 상한 없음 (2026.10.1.부터)

**휴일 초과근무**
- 전체 근무시간 인정 (공제 없음)
- 1일 상한 없음 (2026.10.1.부터)

**공통**
- 하루 초과근무가 1시간 이상일 때만 인정 (평일은 공제 전 기준, 휴일 포함)
- 이틀에 걸친 근무는 시작한 날 기준으로 1번만 공제

**1일 4시간 상한 폐지**
- 「공무원수당 등에 관한 규정」 개정으로 2026년 10월 1일부터 1일 4시간 상한 폐지
- 2026년 9월 30일 이전 기록은 당시 기준(1일 4시간)으로 계산

**월 수당 시간**
- 월 상한 57시간은 기본 초과근무(정액분) 10시간을 포함
- 그래서 기록으로 인정되는 실적은 월 최대 47시간
- 월 실적 합계에서 1시간 미만(분 단위)은 버림
- 수당 시간 = 기본 10시간 + 실적(최대 47시간)

**급량비**
- 평일: 오전 1시간 이상 → 1개, 오후 1시간 이상 → 1개
- 평일: 각각 미만이어도 합산 60분 이상 → 1개
- 휴일: 1시간 초과 근무 → 1개
- 하루 최대 2개 / 월 최대 20개 / 1개 9,000원

## 사용 방법

1. 스마트폰으로 https://seowonjangbu.vercel.app 접속
2. 크롬 브라우저 메뉴 → **홈 화면에 추가** (앱처럼 설치, 이름은 '야근밥')
3. 매일 출근 시 **출근** 버튼 탭
4. 퇴근 시 같은 자리의 **퇴근** 버튼 탭
5. 놓친 날은 **근무 입력** 버튼으로 소급 입력
6. 장부 식당에서 먹은 날은 **식사 입력** 버튼으로 금액 입력
7. 임시공휴일이 생기면 달력 아이콘(**휴일 설정**)에서 그 날짜를 휴일로 지정
8. 잘못 기록했으면 내역에서 그 줄을 눌러 **수정**
9. 규정이 바뀌면 **설정 → 계산 규칙**에서 시행 월부터 새 규칙 추가


## 특징

- **개인정보 보호:** 모든 데이터는 본인 기기에만 저장, 서버 전송 없음
- **무료 운영:** 서버 없는 구조로 유지비용 0원
- **다중 사용자:** 링크 공유 시 각자 기기에 독립적으로 저장
- **오프라인 작동:** 인터넷 없이도 기록 및 조회 가능
- **PWA 지원:** 홈화면 설치 후 네이티브 앱처럼 실행


## 유의사항

- 본 앱은 **참고용**이며 공식 급여 시스템과 연동되지 않습니다
- 데이터는 브라우저별로 독립 저장됩니다 (크롬 ≠ 삼성브라우저)
- 앱을 삭제하거나 브라우저 데이터를 초기화하면 기록이 사라집니다
- 복무 규정이 바뀌면 `설정 → 계산 규칙`에서 맞춰 주세요. 규칙에 없는 방식으로 바뀌면 계산 로직 업데이트가 필요합니다
- 매년 다음 해 공휴일(월력요항)이 발표되면 `src/lib/holidays.ts` 갱신이 필요합니다
